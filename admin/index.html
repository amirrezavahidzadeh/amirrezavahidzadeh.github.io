How do I get an access key? (one minute, once)
  1. Log in to GitHub and open this page.
  2. Name it “site admin”. Set an expiry you like (one year is fine).
  3. Under Repository access, choose Only select repositories and pick the site repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate it, copy it, paste it above. Treat it like a password.
